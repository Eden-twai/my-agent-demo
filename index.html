Topic: 技術問題解決方法和流程

很好問題！以下是我能幫你解決技術問題的方式和最佳實踐：

📋 如何有效提出技術問題

1. 清楚描述問題

  • 你遇到的具體現象（錯誤信息、奇怪行為等）
  • 預期結果是什麼
  • 環境信息（操作系統、編程語言版本、依賴版本等）

好例子：

CODE ⧉ Copy
Python 3.11 中，使用 FastAPI + SQLite，
當執行 POST /users 時，返回 422 錯誤：
"validation error for UserSchema: email field required (type=value_error.missing)"
但我已經在 request body 中傳入 email 了。

2. 提供相關代碼或配置

  • 最小化的重現代碼片段（只包含問題部分）
  • 相關的配置文件
  • 完整的錯誤堆棧跟蹤（traceback）

3. 說明已嘗試過的方案

  • 哪些解決方法試過了但失敗
  • 搜尋過哪些資源
  • 幫助我快速定位問題根源

🛠️ 我能提供的技術支持

類別 示例
編程語言 Python、JavaScript/TypeScript、Bash、Go 等
框架與工具 FastAPI、Django、Express、Hono、React、Bun 等
DevOps Docker、Kubernetes、CI/CD、環境配置
數據庫 SQL、SQLite、Postgres、數據模型設計
系統/網絡 DNS、TCP/IP、日誌分析、性能調優
文件操作 讀寫文件、數據轉換、格式處理
自動化 腳本開發、流程自動化、計劃任務

🚀 我的工作方式

  1. 分析問題 → 理解根本原因而非表面症狀
  2. 提供方案 → 通常給出多個選項，說明優缺點
  3. 實現代碼 → 直接幫你寫/修改代碼文件
  4. 測試驗證 → 在本地環境執行驗證方案是否有效
  5. 文檔記錄 → 將解決方案和經驗保存到 Knowledge，便於未來參考

💡 特殊功能

  • 讀寫文件：檢查和修改你的代碼
  • 執行命令：直接運行測試、安裝依賴、調試
  • 網絡搜索：查找文檔、解決方案、最佳實踐
  • 記憶系統：記住你的項目細節和解決過的問題
  • 子任務代理：複雜問題可以分解成多個並行任務
